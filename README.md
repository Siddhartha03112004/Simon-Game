# 🎮 Simon Says Game

A classic **Simon Says memory game** built using **HTML, CSS, and JavaScript**.  
The game challenges the player’s memory by generating an increasing sequence of colors that must be repeated correctly.

---

## 🚀 Features

- Interactive and colorful user interface
- Random color sequence generation
- Level-based progression
- Real-time user input validation
- Game over detection with restart option
- **Highest score tracking using localStorage**
- Visual feedback for both game and user actions

---

## 🧠 How the Game Works

1. Press any key to start the game.
2. A random color flashes on the screen.
3. Click the buttons in the same order as shown.
4. Each new level adds one more color to the sequence.
5. The game ends if a wrong button is pressed.
6. The highest score is saved and displayed permanently.

---

## 🛠️ Tech Stack

- **HTML5** – Structure of the game
- **CSS3** – Styling and animations
- **JavaScript (ES6)** – Game logic and DOM manipulation
- **LocalStorage** – Persistent high score storage
